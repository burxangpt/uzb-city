# BURXANGPT CITY

3D-город подписчиков: 632 дома с никами и шалаш хозяина в центре.

- Ссылки (канал, кнопки «Подписаться») меняются в одном месте: `config.js`
- Список ников: `data.js` (первый ник — хозяин, шалаш; остальные — дома)
- Публикация: GitHub Pages (Settings → Pages → Deploy from a branch → main / root)
- Локально открывать нужно через сервер (`python3 -m http.server`), двойной клик по index.html не сработает.
